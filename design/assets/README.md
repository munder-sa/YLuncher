# YLuncher design assets

仕様書 §9.1 の素材置き場。実装担当が `app/src/main/res/` に変換して使う。

## アプリケーションアイコン（方向性B「スプリット」で確定、2026-10-28）

モチーフ：分割画面そのもの。左パネル（60%、再生△＝動画）＋右パネル（40%、音符＝音楽）。
ホーム画面の形（左にアプリ／動画、右にパネル／音楽）をアイコンにしている。

| ファイル | 用途 |
|---|---|
| `icon_background.svg` | アダプティブアイコンの背景レイヤー（108×108 フルブリード） |
| `icon_foreground.svg` | 前景レイヤー（透明地、パネル＋グリフ） |
| `icon_monochrome.svg` | モノクロレイヤー（白のシルエット、グリフは抜き）。テーマアイコン用 |
| `icon_full.svg` | 背景＋前景を合成した単体版（アダプティブ非対応の用途向け） |

### パレット
- 背景：`#17171D` → `#0B0B0F` の縦グラデーション（ほぼ黒）
- パネル：`#2E2E38`（濃いグレーがかったスレート）
- アクセント：`#8FE63B`（ライムグリーン）

### ジオメトリ（viewBox 0 0 108 108）
- アートワークはアダプティブアイコンのセーフゾーン（中央約66%）内に収めている
- 分割グループ：x 24〜84（幅60）、y 25〜83（高さ58）、ギャップ4
- 左パネル幅34／右パネル幅22 ≒ 61:39（純正分割 60:40 に寄せた）
- グリフは Material Symbols の play_arrow / music_note のパスを流用（仕様 §9.1 の「標準アイコンは Material Symbols」と整合）

## 代替ジャケット画像（2026-10-28 作成）
| ファイル | 用途 |
|---|---|
| `artwork_placeholder.svg` | 原データ（1024×1024） |
| `artwork_placeholder.png` | 書き出し（1024×1024） |

デザイン：アイコンの右パネル（音楽タイル）をそのまま大きくしたもの。アイコンの背景グラデの上に `#2E2E38` の角丸タイル（560×560、rx 96）＋ライムの音符を中央配置。「ジャケットが無い」ことをエラーっぽく見せず、メディアカードの中で意図した絵として収まるようにしている。

## ホーム壁紙（2026-10-28 作成）
| ファイル | 用途 |
|---|---|
| `wallpaper.svg` | 原データ（1920×1080） |
| `wallpaper.png` | 書き出し（1920×1080、仕様指定の納品形式） |

デザイン：ほぼ黒（`#101016`→`#0A0A0E`）の上に、分割パネルのモチーフを白 4.5% でごく薄く中央配置し、分割の溝にライムの細線（12%）を1本。ホームの UI の背後に敷く前提なので主張は最小限。モチーフ全体が中央の 880×500 に収まっているため、4:3／1:1／21:9 へセンタクロップしても主要部分は切れない（preview_assets.png で確認済み）。濃さは SVG の opacity を変えれば調整できる。

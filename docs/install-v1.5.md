# YLuncher v1.5 導入手順（GT8D）

## 設定画面の開き方

**ドックの一番下にある「アプリ一覧」（点が9つのアイコン）を長押しする。左パネルのときはドックが左端、右パネルとホームでは右端にある。** タップではアプリ一覧が開く。

この手順書は [v1.0 導入手順](install-v1.0.md) からの差分。前提・接続、ビルド環境、本体→中継のインストール順、初回の許可、よくあることは同書を使う。以下のコマンドは利用者向けの例で、今回ビルド・adb・場面テストは実行していない。

## 1. ビルドとインストール

v1.0 手順 §2 の切り替えを次に置き換える。作業中の変更は先に整理する。

```sh
git switch v1.5
```

同書 §2 の本体・中継の debug APK をビルドし、§3 の `install -r` で本体→中継の順に入れる。v1.0 から更新する場合も同じ署名鍵を使う。APK の出力先と接続方法は同じ。初めて導入する場合は §4 の許可も済ませる。

## 2. 初回の設定移行

v1.0 の設定（版2）は v1.5 の初回起動で版3へ移行する。元の JSON はアプリ内の `files/config-v2-backup.json` に保存され、読み直し確認と改名に成功してから `files/config.json` を版3で書き戻す。正しい既存バックアップは上書きしない。バックアップに失敗した場合は、メモリ上では版3で使い、移行処理では設定ファイルを旧版のままにして次回再試行する。

既定のセットは変わらない（セット1は「YouTube | パネル」、6:4）。左パネルは次の手順で作る。v1.0 に戻す場合は、APK を入れる前の設定復元が必要（§5）。

## 3. 左パネルのセットと入れ替え

1. 設定 →「画面セット」でセットを追加または編集する。
2. 左の「パネル」を選び、右の「アプリ」から相手を選ぶ。右がパネルだった場合は未選択になるため、右のアプリを選び直す。両方パネルにはできない。
3. 比率を選んで保存する。比率は常に左:右で、パネルを含むセットは 4:6・5:5・6:4。既存の「アプリ | パネル」を逆にするなら、**⇄「左右を入れ替える」**で左右と比率を反転して保存できる（6:4→4:6）。
4. ホームやパネルのカードから開く。カード名・配置図は「パネル | アプリ」の並びとなり、ドックは左端。左パネルからアプリを起動すると右側が入れ替わる。
5. 正常に開いたパネル付きセットで、システムの**仕切りをダブルタップ**すると左右が入れ替わり、位置が500ms落ち着いた後に左右と比率がセットへ保存される。もう一度で元に戻る。パネルから別アプリを開いた後、セットの編集・削除後、ホーム・リンク・失敗・全画面化などで保存区間が終わった後は保存しない。プロセス終了後にも引き継がない。両方アプリのセットの入れ替えは保存しない。

リンクは表示用ブラウザを「リンクの行き先」で選び、「ブラウザで分割」にする（既定 Chrome）。左パネルの右のアプリからリンクを開くと「ブラウザ | アプリ」、右パネルなら「アプリ | ブラウザ」（5:5）。ブラウザ付き分割から再度リンクを開いても同じ並びを保つ。

## 4. 追加の動作確認・場面テスト

画面で左ドックと帯が重ならないこと、仕切りの入れ替え後も一覧のスクロール位置・アプリ一覧の開閉・アプリ／セットの選択が保たれることを確認する。

自動の場面テストは v1.0 手順 §6 の準備に加え、Googleマップ（`com.google.android.apps.maps`）を用意する。debug 版の本体・中継が必要。v1.5 で増えた場面は次の7つ。

| 場面名 | 確認する内容 |
|---|---|
| `set_leftPanel_cold` | 冷えた状態から左パネル・右 YouTube を開く |
| `set_leftPanel_warm` | 温まった状態でも同じ並びで開く |
| `leftPanel_launchApp` | 左パネルからマップを起動し、右だけを入れ替える |
| `leftPanel_dividerSwap` | 仕切りの往復ダブルタップ、位置・保存した左右と比率の一致 |
| `leftPanel_link` | 右 YouTube のリンクを左ブラウザで開く |
| `leftPanel_link_twice` | 2回目もブラウザの側と相手を保つ |
| `set_leftToRightPanel` | 左パネルから既定の右パネルのセットへ切り替える |

```sh
bash scripts/device-scenarios.sh
bash scripts/device-scenarios.sh --with-ylauncher-home
bash scripts/device-scenarios.sh --with-ylauncher-home --only leftPanel_dividerSwap
```

`--only` でも前提場面を先に実行する。`--with-ylauncher-home` は YLuncher を既定ホームにした場面も追加する。スクリプトはテスト用の左パネルセットを追加する前に、設定を PC の結果フォルダの `config-backup.json` と端末の `files/config-scenario-backup.json` に退避する。終了時（途中失敗を含む）に設定を戻して本体を停止し、端末の退避を消す。前回の退避が残っていたら次回開始時に先に復元する。移行用の `config-v2-backup.json` とは別のファイル。

結果は `build/device-scenarios/<日時>-<PID>/summary.md`。`cleanup FAIL` があれば設定の復元に失敗しているため、報告に示された退避ファイルを確認する。

## 5. v1.0 に戻す

[v1.0 導入手順 §9「v1.5 から v1.0 に戻す」](install-v1.0.md#9-v15-から-v10-に戻す) に従い、**v1.0 を入れる前に** `config-v2-backup.json` を復元して停止し、v1.0 の APK を `install -r -d` で入れる。移行後に v1.5 で変えた設定と左パネルのセットは失われる。

## 1. ユーザーの判断(2026-11-03)
- 表示の形は**案A(ジャケットと歌詞の切り替え)**。案B・案C は ① では使わない。
- 切り替えボタンのアイコンは**案1「吹き出し+行」**。囲みは**角丸の四角**(丸は目立ちすぎる)で、小さめ。
- 切り替えボタンはカードからはみ出さない。囲みの右端は内容の右端(シークバーの右端)にそろえる。
- 歌詞の上下の端は薄くぼかす。
- 前へ/次へは**曲送りのまま**。
- 歌詞が無いときは、**自動でジャケットに戻す**。
- 歌詞は ① と ② の**両方**に出す。② は、アーティストの下に今の行を1行だけ出す。

### 1.1 モックからの変更(レビューを受けて Claude が決めた。ユーザーの確認待ち)

- アプリ名の行は、ボタンを出すときだけ高さ 48dp(既存は 44dp)。囲み 48dp を行に収めるため。

## 3. 歌詞の入手(LRCLIB)
### 3.1 問い合わせ
- **LRCLIB**(`https://lrclib.net`。無料・API キー不要)。`GET /api/get`。公式文書(lrclib.net/docs.md)で、必須は `track_name`・`artist_name`、`album_name`・`duration` は任意(`duration` は 1〜3600 秒)、`duration` は ±2 秒で照合と確認済み。
- 引数:
  - `track_name` = メタデータの曲名。**曲名が無い(既存の表示でアプリ名を代わりに出している)ときは問い合わせない。**
  - `artist_name` = アーティスト。**無ければ問い合わせない。**
  - `album_name` = アルバム名(`METADATA_KEY_ALBUM`、空白でないときだけ)。
  - `duration` = 長さの秒(四捨五入)。1〜3600 の範囲外・不明なら付けない。
- 通信: `HttpURLConnection`(新しいライブラリは入れない)。接続 5 秒・読み取り 5 秒、リダイレクトを追わない、応答は 512KB まで(超えたら Failed)。`User-Agent: YLuncher/<versionName> (https://github.com/munder-sa/YLuncher)`(versionName は `PackageManager` から)。
- **通信とディスクは IO スレッドで行う**。取り消されたら接続を切る(`disconnect()`)。
- **検索で補う(r1.2)**: `/api/get` の結果が Plain または Missing(404・400・200 で歌詞なし。instrumental は除く)のときは、続けて `GET /api/search?track_name=…&artist_name=…` を1回だけ呼ぶ。返った配列(最大 20 件)から、`instrumental` が false で `syncedLyrics` を §4 で読んで1行以上あり、長さが分かっていれば `duration` との差が 2 秒以内のものを候補にし、①アルバム名が一致(大小・前後の空白を無視)②長さの差が小さい③配列の順、で1件選んで Synced にする。候補が無い、または検索が失敗(IOException・200 以外・JSON が読めない)したときは、`/api/get` の結果(Plain・Missing)をそのまま使う。検索の 429 は §3.3 の全体の待機に使う。
  - 実機で、Apple Music の「夜の踊り子 / サカナクション / sakanaction / 302 秒」は `/api/get` が平文だけの記録(303 秒)を返し、検索では 302 秒前後の同期歌詞の記録が 10 件以上あった(2026-11-03)。

### 3.2 応答の振り分け(上から順に判定)
| 条件 | 状態 |
|---|---|
| 接続できない・タイムアウト(`IOException`) | Offline |
| 429 | Failed(`Retry-After` の秒を全体の待機に使う。§3.3) |
| 404、400 | Missing |
| その他の 200 以外、JSON が読めない、512KB 超 | Failed |
| 200 で `instrumental = true` | Missing |
| 200 で `syncedLyrics` を §4 で読んで1行以上ある | Synced |
| 200 で `plainLyrics` が空白でない | Plain |
| それ以外の 200 | Missing |

### 3.3 いつ取るか
- **歌詞表示がオン(§5.1)のときだけ**取る。オフの間は通信しない。
- **曲の鍵** = (`pkg`、メタデータの曲名、アーティスト、アルバム、長さの秒)。前後の空白を除き小文字にしたもの。鍵が変わったときだけ取り直す(再生位置・再生/停止・ジャケットの更新では取り直さない)。
- 鍵が変わったら **600ms 待ってから**取る。待つ間・通信中に鍵が変わった、オフになった、再生情報が消えたときは、その取得を取り消し、遅れて返った結果も捨てる(要求ごとの世代番号で判定)。
- **全体の待機**: 429 を受けたら、`Retry-After`(秒。無い・読めないときは 60 秒)の間、**どの曲についても**問い合わせない。曲送り・オン/オフでも待機は解けない。待機中に取るべき曲は、待機が明けたら取る。
- **取り直し**: Offline・Failed のとき、同じ鍵が続いていれば取り直す。初回のあと**最大 3 回**(30 秒・60 秒・90 秒後。全体の待機があればその明けと遅いほう)。鍵が変わる、またはオフ→オンで回数を 0 に戻す。
- 取得中は Loading。

### 3.4 キャッシュ
- アプリの内部の `files/lyrics/` に 1 曲 1 ファイル。ファイル名は曲の鍵(`pkg` を除く4項目)を JSON の配列にして SHA-256 の16進。最大 300 件、書いた時刻の古いものから消す。
- 保存形式に版 `"v":2` を持たせ、版が無い・違うファイルは無いものとして扱う(r1.2 で検索の補完を足したため、r1.1 の Plain・Missing を取り直させる)。
- 保存するのは Synced・Plain・Missing。**Missing は 7 日で期限切れ**(読むときに判定し、切れていれば無いものとして取り直す)。Offline・Failed は保存しない。
- 読めない・壊れたファイルは無いものとして扱う(消して取り直す)。書き込みに失敗しても、取れた歌詞は表示する。
- メモリには今の曲の状態だけを持つ(曲ごとのメモリのキャッシュは持たない)。
- 設定の「デフォルトに戻す」ではキャッシュを消さない。

## 4. 同期歌詞の読み方と今の行
- 各行の `[mm:ss.xx]`・`[mm:ss.xxx]`・`[mm:ss]` を時刻として読む(秒は 00〜59。外れた時刻はその行ごと捨てる)。1行に時刻が複数あれば、その数だけ行を作る。`[ar:…]` などのタグの行は捨てる。
- `[offset:±ms]`(最初のもの1つだけ使う)があれば全行の時刻から offset を引く(+ は歌詞を早める。0 未満は 0)。
- 文字が空の行は「♪」。同じ時刻の行は、元の順のまま並べる(安定な並べ替え)。
- **今の行** = 時刻が再生位置以下の最後の行。最初の行より前なら無し(-1)。
- **再生位置の求め方**: 歌詞を表示している部品が、最新の `NowPlaying` と時計(`SystemClock.elapsedRealtime()`。テストでは差し替える)から `positionAt()` で 200ms ごとに求める。再生中でないときは求め直さない(位置は止まっている)。表示していない(オフ・Sets 表示でカードが無い・ジャケット表示中)ときは何もしない。既存のシークバー用の 500ms の位置は変えない。

## 5. 表示
### 5.1 設定
- `LauncherConfig.lyricsEnabled: Boolean = false`(既定はオフ)。① の切り替えボタンで変え、保存する。② はこの設定に従う。
- `CONFIG_VERSION` は変えない(欠けた項目は既定値で読む)。「デフォルトに戻す」で false に戻る。

### 5.2 ① ホームのミニプレイヤー
**切り替えボタン**
- 見える囲み 48dp の正方形、角丸 12dp。図柄は「吹き出し+行」の `ImageVector`(モックの SVG から写す)、見た目 28dp。押せる範囲は 72dp 四方。
- 色: オフ = 地 `Palette.Control`+白い図柄、オン = 白い地+`Palette.Background0` の図柄。
- **使えないとき**(オンで Missing・Offline・Failed、または歌詞の場所が狭い §5.2 下): オンの見た目のまま不透明度 0.38。押せる(押すとオフ)。
- 説明(contentDescription): オフ「歌詞を表示」、オン「ジャケットを表示」、使えないとき「歌詞なし。押すと歌詞表示をオフ」(「歌詞なし」は理由に応じて「オフライン」「歌詞を取得できません」「表示する場所がありません」)。
- 置き場所:
  - アプリ名の行を出すとき: 行の右端。このとき行の高さは 48dp(高さの計算でも 48dp を使う)。囲みは行の縦中央、右端を内容の右端にそろえる。押せる範囲は囲みから左右・上下に 12dp ずつ広げ、右と上はカードの余白に重なってよい。
  - アプリ名の行を出さないとき: 曲名・アーティストの行の右端。☆があるときは「曲名の列 → 8dp → 囲み → 8dp → ☆の丸」(☆の丸の右端が内容の右端)。押せる範囲は☆と重ならないよう左と上下に広げる。☆が無いときは囲みの右端を内容の右端にそろえ、左右上下に 12dp 広げる。
- 出さないとき: 再生情報が無い(待ち受けのカード)、メタデータの曲名が無い、アーティストが無い(どれも問い合わせないため。オンでも通信は起きない)。

**歌詞の場所の大きさ**
- 既存の計算の「固定要素の高さ」を引いた残り(=今ジャケットに使える縦の長さ。幅での頭打ちをしない)を**歌詞の高さ**とする。幅は内幅いっぱい。
- 余白の段(通常・詰め・最小)の選び方は既存のまま(ジャケットの大きさで選ぶ)。歌詞を出すかどうかで段を変えない(切り替えで余白が跳ねないように)。
- 歌詞の高さが **120dp 以上**のときだけ歌詞を出す。未満なら既存どおりジャケット(入らなければ何も出さない)を出し、ボタンは「使えないとき」の見た目。

**歌詞の中身**
- **Synced**(r1.3: 実機確認でユーザーが参考の録画を示して決めた): 
  - すべての行を同じ大きさ(24sp)・太字(Bold)・**左揃え**で並べる。長い行は折り返す(最大 2 行。超えたら省略記号)。行の間は 16dp。
  - **今の行を歌詞の場所の縦の中央**に置く。今の行が次の行に進んだら 300ms で上へ送る(端末のアニメーションの速さの設定に従う)。2行以上の飛び・戻りはすぐ切り替える。最初の行より前は、最初の行を中央に(塗りなし)。
  - **今の行の塗り**: 今の行は、行の始まりの時刻から次の行の時刻(最後の行は 5 秒後、ただし曲の長さまで)にかけて、左から右へ文字が白く塗られていく(カラオケ風)。塗りの割合 = 経過 ÷ 行の長さ(0〜1)。塗った所は白(不透明度 1.0)、まだの所は白の不透明度 0.45。境目は 24dp ほどのぼかし。複数行に折り返した行は、1行目を塗り終えてから2行目を塗る(文字の並び順に沿って塗る)。再生中は画面の更新ごと(毎フレーム)に割合を求め、停止中は止める。
  - 今の行以外の行は白で、今の行からの距離 d(行数)に応じて不透明度を下げる: d=1 は 0.45、d=2 は 0.35、d≥3 は 0.25。
- **Plain**: 冒頭から入るだけを 20sp・白で静止表示(スクロールしない)。
- **Loading**: 中央に「歌詞を探しています…」(`Palette.Muted`・20sp)。
- 上端・下端それぞれ 32dp を透明→不透明のグラデーションでぼかす(Synced・Plain)。
- 歌詞の場所を押しても何もしない。ジャケットを押すとアプリを開く既存の動作は、ジャケットを出しているときだけ。

**自動でジャケットに戻す**
- オンでも Missing・Offline・Failed のときはジャケットを出し、ボタンを「使えないとき」の見た目にする。アプリ名の行に置いているときは、ボタンの左に理由(「歌詞なし」「オフライン」「取得できません」、`Palette.Muted`・20sp、1行で省略)を出し、アプリ名を詰める。曲名の行に置いているときは理由を出さない(説明で伝える)。
- オン/オフの選択は保存したまま。歌詞が取れる曲になれば、オンなら歌詞に戻る。

### 5.3 ② 分割中のパネルのメディアカード
- オンで、①でボタンを出す条件(曲名・アーティストあり)を満たすとき、アーティストの下に**1行分の場所を取る**(曲の間ずっと。歌詞が取れても取れなくてもカードの高さを変えない)。
- 中身: Synced なら今の行(白・`Dims.BodyText`、1行、省略記号。マーキーにしない)。最初の行より前と「♪」の行は `Palette.Muted` の「♪」。それ以外の状態は空。行が変わるときはすぐ差し替える。
- オフ、または条件を満たさないときは場所を取らない(今のカードのまま)。

## 7. テスト
- `LrcParser`: 時刻の3つの書き方、範囲外の時刻、複数の時刻、タグの行、`[offset]`(+・−・0 未満・2つ目は無視)、空の行→♪、同じ時刻の順、今の行(最初より前・ちょうど・最後より後・空)。
- `LrclibClient`: URL(エンコード、アルバム・長さの有無と 1〜3600 の範囲)、曲名またはアーティストが無ければ通信しない、`User-Agent`、§3.2 の表の各行と判定の順(instrumental と歌詞の両方あり、synced が読めず plain あり)、512KB 超。
- `LyricsCache`: 300 件の上限と古い順、Missing の 7 日(作り直したインスタンスでも)、Offline・Failed を保存しない、壊れたファイル、鍵の正規化(大小・空白)。
- `LyricsRepository`: オフで通信しない、600ms(599ms で呼ばない)、待つ間と通信中の曲替え・オフ・再生情報の消失で取り消し・古い結果を捨てる、キャッシュがあれば通信しない、位置・再生状態・ジャケットだけの変化で取り直さない、429 の全体の待機(別の曲・オフ→オンでも守る、`Retry-After` 無し=60 秒)、取り直し(初回+3回、120 秒で5回目なし、鍵替え・オフ→オンで回数を戻す)。
- 設定: 古い JSON で false、true の保存と読み直し、「デフォルトに戻す」で false。
- Compose(Robolectric): ① ボタンの囲み(48dp)と押せる範囲(72dp)を別々に測る、2つの置き場所と☆の有無での右端・間隔・重ならないこと、押すとオン/オフ、Synced で歌詞・ジャケット無し、Missing・Offline・Failed でジャケットに戻り理由が出て押すとオフ、Loading の文言、曲名・アーティスト無しでボタン無し、歌詞の高さ 119/120dp、今の行の強調と 200ms の更新(差し替えた時計を進める)・一時停止で進まない・シークで飛ぶ。② Synced の行・♪・省略、状態が変わっても高さが同じ、オフで場所が無い。既存の HomeMiniPlayer・MediaCard のテストを弱めない。
- 実機(人が確認): Apple Music・YouTube Music で同期のずれ、曲送り、Wi-Fi を切ったときと戻したとき、狭い場面の見た目。

## 8. プライバシー
- オンのときだけ、曲名・アーティスト・アルバム名・長さを lrclib.net へ送る。それ以外(再生アプリ名・位置など)は送らない。
- README と導入手順に「歌詞表示をオンにすると、曲の情報を LRCLIB(lrclib.net)に送って歌詞を探す」と書く。

# v1.5 左パネル対応 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **このプロジェクトでは**: 各 Task は指示書 `tasks/NNN-xxx.md`(+ `.allow`)にして `codex-run` で codex に任せ、司令塔(Claude)が `codex-ask` での点検 → 差分レビュー → `codex-verify` → コミットを行う(`CLAUDE.md`)。ブランチは `v1.5`。

**Goal:** 画面セットごとにパネルを左にも置け、左パネルではドックも左、仕切りのダブルタップの入れ替えをセットに保存し、リンクは「ブラウザ | アプリ」で開く。

**Architecture:** `ScreenSet.left` を `Slot` に広げ(設定の版 3、版 2 から自動移行)、セットの左右を対称に扱う小さな関数群(`panelSide`・`swapped`・`mirrored`)に起動・設定画面・カード・リンクを寄せる。実際のパネルの位置は PanelActivity が窓の座標から `PanelPlacement` を出して `AppGraph` で共有し、ドックの配置・リンク・入れ替えの保存はそれを見る。純正の分割(E)・中継アプリ・隣に開く起動は変えない(実機で左でも動くことを確認済み)。

**Tech Stack:** Kotlin、Jetpack Compose(BOM 2025.01.00)、kotlinx.serialization、Robolectric、bash の場面テスト(`adb.exe`)。

**Spec:** `docs/superpowers/specs/2026-10-31-v1.5-left-panel-design.md`(元の仕様 `docs/superpowers/specs/2026-10-28-gt8d-launcher-design.md` r2.2 の差分)

## Global Constraints

- ブランチ `v1.5`。v1.0 はタグ `v1.0`。main へは v1.5 の完成後に別途判断。
- ビルド・テストは WSL で `/home/munde/tools/gradle-run.sh <引数>`。`--tests` のパターンは引用符で囲む(`'com.gt8d.launcher.x.*'`)。
- 端末操作は `adb.exe -s 192.168.137.248:5555`。codex は adb を実行しない(司令塔が実機で流す)。
- E の値: パッケージ `com.sd.factoryconfig`、クラス `com.sd.factoryconfig.SplitActivity`、`split_shortcur_package`=`"左|右"`、`split_percent` は 3:7→`3:7`、4:6→`2:3`、5:5→`1:1`、6:4→`3:2`、7:3→`7:3`。比率は**左:右**。
- 中継アプリ `com.gt8d.launcher.panel` をパネルの側に渡す。本体 `com.gt8d.launcher` を分割に直接渡さない。
- パネルを含むセットの比率は 4:6・5:5・6:4 のみ(左右どちらのパネルでも)。パネルは片側だけ。
- タッチ領域 72dp(`Dims.MinTouch`)、本文 `Dims.BodyText`、強調色はホーム・パネルで白(`Palette.PanelAccent`)。UI 文言は日本語。
- 全画面のホーム(`HomeWideContent`)・狭いホームのドック位置は変えない。
- 幕の安全タイマー 4 秒(最初の呼び出しから合計。延長しない)。
- テストを弱めない。「左はアプリ固定」を前提にした既存の期待値だけを合わせ、どれを変えたかを報告する。

## Review Focus

1. **v1.0 へ戻したとき設定が消える**: 版 3 で保存した設定を v1.0(版 2 まで)が読むと `decode` が null → 既定値になり、ユーザーのセットが消える。→ Task 1 で、版 2 から移行するときに元の JSON を `config-v2-backup.json` として残す(テストあり)。
2. **リンクで作った分割(ブラウザ | アプリ)の中で仕切りをダブルタップ**: セットではないので保存してはいけない。→ Task 6 のテスト。
3. **仕切りを端まで引いて分割を解いた**(Left→Full): 入れ替えではないので保存しない。→ Task 6 のテスト。
4. **ダブルタップを素早く2回**: 2回とも保存して元の並びに戻る(途中で取りこぼさない、保存が順番に行われる)。→ Task 6 のテスト。
5. **分割を開いたまま設定でセットを並べ替え・編集してから入れ替え**: 番号ではなくセットの id で保存先を決める。→ Task 6 のテスト。

# v1.5 左パネル対応 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **このプロジェクトでは**: 各 Task は指示書 `tasks/NNN-xxx.md`(+ `.allow`)にして `codex-run` で codex に任せ、司令塔(Claude)が `codex-ask` での点検 → 差分レビュー → `codex-verify` → コミットを行う(`CLAUDE.md`)。ブランチは `v1.5`。
> 改訂: 2026-10-31 codex の敵対レビュー(3観点・33件)を反映(r2)。

**Goal:** 画面セットごとにパネルを左にも置け、左パネルではドックも左、仕切りのダブルタップの入れ替えをセットに保存し、リンクは「ブラウザ | アプリ」で開く。

**Architecture:** `ScreenSet.left` を `Slot` に広げ(設定の版 3、版 2 から確かめながら移行)、左右を対称に扱う小さな関数(`panelSide`・`swapped`・`mirrored`)に起動・設定画面・カード・リンクを寄せる。実際のパネルの位置は PanelActivity が窓の座標から `PanelPlacement` を出して `AppGraph` で共有する。入れ替えの保存は「正常に開いたセットの区間」の中で、落ち着いた位置とセットの側を比べて収束させる。純正の分割(E)・中継アプリ・隣に開く起動は変えない(実機で確認済み)。

**Tech Stack:** Kotlin、Jetpack Compose(BOM 2025.01.00)、kotlinx.serialization、Robolectric、bash の場面テスト(`adb.exe`)。

**Spec:** `docs/superpowers/specs/2026-10-31-v1.5-left-panel-design.md`(元の仕様 `docs/superpowers/specs/2026-10-28-gt8d-launcher-design.md` r2.2 の差分)

## Global Constraints

- ブランチ `v1.5`。v1.0 はタグ `v1.0`。main へは v1.5 の完成後に別途判断。
- ビルド・テストは WSL で `/home/munde/tools/gradle-run.sh <引数>`。`--tests` のパターンは引用符で囲む(`'com.gt8d.launcher.x.*'`)。
- 端末操作は `adb.exe -s 192.168.137.248:5555`。codex は adb を実行しない(司令塔が実機で流す)。GT8D では `uiautomator dump` が使えない。
- E の値: パッケージ `com.sd.factoryconfig`、クラス `com.sd.factoryconfig.SplitActivity`、`split_shortcur_package`=`"左|右"`、`split_percent` は 3:7→`3:7`、4:6→`2:3`、5:5→`1:1`、6:4→`3:2`、7:3→`7:3`。比率は**左:右**。
- 中継アプリ `com.gt8d.launcher.panel` をパネルの側に渡す。本体 `com.gt8d.launcher` を分割に直接渡さない。
- パネルを含むセットの比率は 4:6・5:5・6:4 のみ(左右どちらのパネルでも)。パネルは片側だけ。
- タッチ領域 72dp(`Dims.MinTouch`)、本文 `Dims.BodyText`、強調色はホーム・パネルで白(`Palette.PanelAccent`)。UI 文言は日本語。
- 全画面のホーム(`HomeWideContent`)・狭いホームのドック位置は変えない。
- 幕の安全タイマー 4 秒(最初の呼び出しから合計。延長しない)。
- テストを弱めない。変えてよい既存の期待値は「左はアプリ固定」と「設定の版(2→3)」に由来するものだけ。どれを変えたか報告させる。
- Compose の状態をテストのスレッドから書いたら `Snapshot.sendApplyNotifications()`。

## Review Focus

1. **パネルからアプリを替えた後の入れ替え・リンク**: 「パネル | YouTube」→ パネルからマップ → ダブルタップは保存しない。リンクはマップを残す。→ Task 6・7 のテスト。
2. **リンクを続けて2回**: 「ブラウザ | YouTube」で YouTube から再びリンク → 同じ並びで開き直す(全画面にしない)。→ Task 7 のテスト。
3. **起動の途中・Safety の後の位置の変化**: 冷えた起動で4秒を超え Safety の後に E が窓を動かしても保存しない(区間が始まっていない)。→ Task 6 のテスト。
4. **素早い2回の入れ替えと、保存の遅れ**: 保存を遅らせても最後の位置に収束する。→ Task 6 のテスト(AppGraph の購読を通す)。
5. **v1.0 へ戻す**: 移行のバックアップが原子的に作られ、戻す手順が導入手順書にある。→ Task 1 のテスト、Task 9 の手順書。

# ミニプレイヤーの歌詞表示 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **このプロジェクトでは**: 各 Task は指示書 `tasks/NNN-xxx.md`(+ `.allow`)にして `codex-run` で codex に任せ、司令塔(Claude)が `codex-ask` での点検 → 差分レビュー → `codex-verify` → コミットを行う。ブランチは `lyrics`。

**Goal:** ホームのミニプレイヤーでジャケットと同期歌詞を切り替えられ、分割中のパネルのカードにも今の行を1行出す。

**Architecture:** 取得(LRCLIB)・キャッシュ・LRC の読み取りを `media/lyrics/` に閉じ込め、`LyricsRepository` が `StateFlow<LyricsState>` を出す。UI は状態と `NowPlaying` を受け取り、共用の `rememberLyricIndex` で今の行を求めて描く。設定は `LauncherConfig.lyricsEnabled` の1項目。

**Tech Stack:** Kotlin、Jetpack Compose(BOM 2025.01.00)、kotlinx.serialization、`HttpURLConnection`、coroutines-test、Robolectric。

**Spec:** `docs/superpowers/specs/2026-11-03-lyrics-design.md`(r1.1。モック `design/mocks/lyrics-miniplayer.html`)

## Global Constraints
- ブランチ `lyrics`。ビルド・テストは `/home/munde/tools/gradle-run.sh`。`--tests` は `:app:testDebugUnitTest --tests '...'` の形(引用符・`:app:` 付き)。codex は adb を実行しない。
- 新しいライブラリを入れない。BuildConfig を有効にしない(versionName は `PackageManager`)。
- タッチ領域 72dp(`Dims.MinTouch`)、本文 20sp 以上(`Dims.BodyText`)、歌詞にマーキー・点滅を使わない、動きは ① の「次の行へ」の 300ms だけ。
- 歌詞表示がオフ(`lyricsEnabled = false`、既定)の間、曲名・アーティストが無い間は通信しない。通信とディスクは IO スレッド(`AppGraph` の既存スコープは Main なので、そこで直接行わない)。
- テストの歌詞は架空のダミー文。
- 既存の HomeMiniPlayer・MediaCard・PanelScreen・config のテストを弱めない。
- テストは触ったパッケージだけ流す。全テスト(`codex-verify`)は最後に1回。

## Review Focus
1. **曲を素早く送る/通信中に曲が変わる**: 最後の曲だけ取り、古い応答は捨てる。→ Task 131 `staleResponseIsDropped`・`cancelWhileInFlight`。
2. **429 を曲送りで回避しない**: 待機中はどの曲も問い合わせない。→ Task 131 `globalBackoffAcrossTracks`・`backoffSurvivesToggle`。
3. **一時停止・シーク**: 一時停止中は今の行が進まない、シークで次の更新(200ms)に飛ぶ、飛びは送りの動き無しで切り替わる。→ Task 131 `LyricIndexTest`、Task 132 `jumpSnapsWithoutAnimation`。
4. **ラジオ・ポッドキャスト(曲名をアプリ名で埋めている・アーティスト無し・長さ 0 や 3600 秒超)**: 通信しない/`duration` を付けない、ボタンを出さない。→ Task 130 `noTitleOrArtistSkipsRequest`・`durationRange`、Task 132 `noMetaTitleHidesToggle`。
5. **オフにできない状態を作らない**: 歌詞が無い・オフライン・狭いときもボタンは押せてオフになる。→ Task 132 `unavailableToggleStillTurnsOff`。

# YLuncher 更新履歴

新しい版が上。導入・更新の手順は [導入手順](install.md) を参照。版は本体・中継で同じ(`versionName` / `versionCode`)。

## 2.3.7(2026-11-17)版70

- Apple Music の歌詞が行単位(単語ごとの時刻なし)しかない曲でも、歌詞を出すようにした。これまでは Apple の単語単位の歌詞しか使わず、AMLL・LRCLIB にも無い曲(国内インディーなど)は Apple Music 本体に歌詞があっても「歌詞なし」になっていた。順番は Apple の単語単位 → AMLL の単語単位 → Apple の行単位 → LRCLIB。行単位の歌詞は今の行を強調する表示(単語ごとの色の変化なし)。
- Apple の行単位の歌詞は30分覚えておき、同じ曲ではすぐに出す。一時的な通信失敗で、表示中の歌詞を消さない。
- 診断ログ: Apple の歌詞が使えなかったときの理由コード(`detail=`)と行数を記録する(歌詞の文字は記録しない)。
- 確認: 全テスト成功、実機(GT8D)で DYGL「All Tomorrows」の歌詞の表示。

## 2.3.6(2026-11-17)版68

- ジャケットの取得に失敗した後、ネットワークが「つながった」時点だけでなく「実際に通信できるようになった」時点でも取り直す(ネットワークごとに1回。電波の強さの変化では繰り返さない)。
- 同じ曲で画像の大きさだけが変わったとき(補った画像の後に本物が届いたときなど)、背景色を一瞬灰色にせず、前の色のまま切り替える。
- 再生位置が不明(-1)のときは 0 として扱い、更新時刻が今より先のときは位置を進めない。
- 診断ログ: 通知の `[Artwork] notif` の重複抑止を、ジャケットが揃った・通知が消えた・リスナーが切れた時点で解除する。
- 確認: 全テスト成功、実機(GT8D)で再生位置・曲送り・ジャケットと背景色・パネルの開け閉め。

## 2.3.5(2026-11-17)版66

- 不具合の修正: 端末の起動直後などに Apple Music のジャケットが届かず、ミニプレイヤー(ホーム・パネル)のジャケットと背景色が欠けることがあった。Apple Music は先に画像の URL だけを送り、後から画像を送ってくる。画像が届かないまま URL だけの状態が2秒続いたら、その URL から自分で取得して補う。失敗したときは少し待って再試行し、ネットワークがつながったときにも取り直す。取得する画像は 8MB まで、最大辺 512px に縮める。
- 不具合の修正: パネルを閉じたとき、裏で止まっているホームの古い曲の状態で、背景色が消えることがあった。
- 診断ログに `[Artwork]` を追加した(画像の有無・大きさ・URL の種類だけで、URL そのものは記録しない)。
- 確認: 全テスト成功、実機(GT8D)で起動直後の Apple Music の再生・曲送り・パネルの開け閉め。

## 2.3.4(2026-11-10)版63

- ドック最上部のステータスを、アプリの列から切り離した別のカードにした。上段に SIM の電波(4 本のバー)と回線の種類(5G・4G・3G・2G)、下段に Wi-Fi と Bluetooth。アイコンを 20dp → 30dp に大きくした。ホームと分割時のパネルの両方。
- SIM なし・機内モード・圏外を出し分ける。電話機能の無い端末では上段を出さない。新しい権限 `READ_BASIC_PHONE_STATE` は通常の権限で、許可の画面は出ない。電波の監視は画面が見えている間だけ。
- 不具合の修正: 分割中のパネルの最上部に出ていた灰色の帯(高さ 24dp)を消した。分割中は Android がステータスバーの分を強制的に空け、標準の画面の枠がそれを余白にしていた。
- 確認: 全テスト成功、実機(GT8D・車載モード・Desktop Head Unit への投影)でホーム・分割(パネルが左・右)のドックと上端。
- 端末側の任意の設定: システムの右上のアイコン(ドックと重複)と時刻は、`adb shell settings put secure icon_blacklist clock,rotate,headset,wifi,mobile,airplane,battery` で消せる。戻すときは `adb shell settings delete secure icon_blacklist`。アプリはこの設定が無くても動く。

## 2.3.2(2026-11-06)版56

負荷を減らした(見た目・動きは変えていない)。

- 歌詞の前奏・間奏の「●●●」は、点灯数が変わる時刻だけ描き直す(毎フレームの更新をやめた)。
- 時計は分の切り替わり・時刻の変更・タイムゾーンの変更の知らせで更新し、文字の大きさの計算を使い回す。
- パネルを最初に開くとき、見えている画面のアイコンを先に用意し、残りは表示の後に読み込む。
- 画面が見えていない間は、再生位置などの更新を止める。
- 分割がそろったかの確認(使用状況の照会)を裏のスレッドで行い、照会する記録を「前面に出た」ものだけに絞る。
- 最後に開いたセットの番号を覚えておき、毎回ファイルを読まない。
- 不具合の修正: Apple Music 接続の再試行の待ちを、端末の日時ではなく経過時間で測る(時刻の補正で待ちが延びない)。音楽アプリの曲情報の最初の取得に失敗しても、次の知らせで取り直す。最後のセット番号の読み込みの一時的な失敗を固定しない。
- 計測(1920×1080・30Hz のミラー表示、同じ版の対照と交互に3組): 前奏区間の CPU 中央値 8.87% → 6.17%(1コア=100%)。窓が約3.5秒と短いので目安。実車の 60Hz は未検証。詳細は [作業記録](performance/2026-11-06-followup-implementation.md#第三段階の実機確認-2026-11-06-夜司令塔-claude)。
- 確認: 全テスト 4,334件成功、実機でホーム・Apple の歌詞・分割・パネルの切替・HOME 復帰。
- 試して採用しなかったもの: 単語の塗りと歌詞の上下端の描き方の変更(画素の差が許容を超えた)、操作から収録した起動用プロファイル(効果が誤差内)。

## 2.3.1(2026-11-06)版51

- 歌詞の前奏・間奏で、点灯数が変わらない間の不要な描画を減らした。
- 音楽アプリからの知らせでは、変わったセッションの項目だけを更新する(再生位置の知らせごとに全部を読み直さない)。
- 「よく使うアプリ」の7日間の集計を60秒間使い回す(順位の反映は最大約60秒遅れる)。
- 計測(1920×1080・30Hz のミラー表示): 前奏区間の CPU 中央値 31.23% → 7.90%(1コア=100%)。単語を塗る区間は改善なし。実車の 60Hz・長時間は未検証。詳細は [歌詞描画の記録](performance/2026-11-06-lyrics-render-comparison.md)・[通知・履歴の記録](performance/2026-11-06-runtime-cost.md)。
- 確認: 全テスト 4,098件成功、実機で Apple 接続の復元・歌詞・分割・HOME 復帰([Task 201](../tasks/201-v2.3.1-release.md))。

## 2.3.0(2026-11-04)版47

- Apple Music で再生中の曲は、Apple の単語同期歌詞を優先して表示する(取れなければ AMLL → LRCLIB)。ホームと分割パネルの両方。
- 設定 →「音楽」→「Apple Music の歌詞」から、YLuncher 内で Apple にログインして接続できる。接続情報は端末内に暗号化して保存し、再起動・更新の後も復元する。手動のトークン入力もある。
- 接続を解除するとき、YLuncher 内の Web ログイン情報も消すかを選べる。
- Apple 歌詞の通信で IPv6 の接続待ちが続くとき、IPv4 も素早く試す。
- ジャケット背景を最大3色にした(文字のコントラスト 4.5:1 以上を保つ)。
- 既知: 起動直後に設定画面が一時的に黒くなることがある(原因未特定)。確認の範囲は [Task 190](../tasks/190-v2.3.0-release.md)。

## 2.2.0(2026-11-04)版39

負荷を減らした(見た目・動きは変えていない)。

- 歌詞は、見えている行と出入りする行だけを組み立てる。
- ホーム・パネルのアプリ情報(一覧・名前・アイコン)を裏で取って共有する。
- 本体のリリース版に R8 をかけた(APK 約 42MB → 約 2.6MB)。
- ベースラインプロファイルを入れた(端末の待機中の最適化の後に効く。すぐ効かせるなら `adb shell cmd package compile -r bg-dexopt com.gt8d.launcher`)。
- 実機の計測(2.1.0 比): ホームに戻るまで 120ms → 83ms、1フレームの処理の 90% 値 14.2ms → 11.3ms。

## 2.1.0(2026-11-04)版37

- 歌詞の取得元に [AMLL TTML DB](https://github.com/amll-dev/amll-ttml-db) を足した(単語ごとの時刻つき)。Apple Music の曲はカタログの曲 ID で直接、他のアプリは1日1回取る索引から曲名・アーティストで決まるときだけ取る。
- 優先順位は AMLL → LRCLIB の同期歌詞 → LRCLIB の平文。AMLL に無い曲は、再生のたびに AMLL だけを確かめ直す。

## 2.0.0(2026-11-04)版33

- ミニプレイヤーとパネルのメディアカードの地を、ジャケットから取った暗い色のグラデーションにした。
- 歌詞の見た目: 次の行を少し明るく、行ごとに少しずつ遅れて動く送り、今の行以外をわずかに縮める。

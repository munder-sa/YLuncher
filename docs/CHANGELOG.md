# YLuncher 更新履歴

新しい版が上。導入・更新の手順は [導入手順](install.md) を参照。版は本体・中継で同じ(`versionName` / `versionCode`)。

## 2.3.2(準備中)

実機確認用は 2.3.2-beta4 / 55。正式版は実機確認の後。

- 歌詞の前奏・間奏の「●●●」は、点灯数が変わる時刻だけ描き直す(毎フレームの更新をやめた)。
- 時計は分の切り替わり・時刻の変更・タイムゾーンの変更の知らせで更新し、文字の大きさの計算を使い回す。
- パネルを最初に開くとき、見えている画面のアイコンを先に用意し、残りは表示の後に読み込む。
- 画面が見えていない間は、再生位置などの更新を止める。
- 分割がそろったかの確認(使用状況の照会)を裏のスレッドで行い、照会する記録を「前面に出た」ものだけに絞る。
- 最後に開いたセットの番号を覚えておき、毎回ファイルを読まない。
- 不具合の修正: Apple Music 接続の再試行の待ちを、端末の日時ではなく経過時間で測る(時刻の補正で待ちが延びない)。音楽アプリの曲情報の最初の取得に失敗しても、次の知らせで取り直す。最後のセット番号の読み込みの一時的な失敗を固定しない。

## 2.3.1(2026-11-06)版51

- 歌詞の前奏・間奏で、点灯数が変わらない間の不要な描画を減らした。
- 音楽アプリからの知らせでは、変わったセッションの項目だけを更新する(再生位置の知らせごとに全部を読み直さない)。
- 「よく使うアプリ」の7日間の集計を60秒間使い回す(順位の反映は最大約60秒遅れる)。
- 計測(1920×1080・30Hz のミラー表示): 前奏区間の CPU 中央値 31.23% → 7.90%(1コア=100%)。単語を塗る区間は改善なし。実車の 60Hz・長時間は未検証。詳細は [歌詞描画の記録](performance/2026-11-06-lyrics-render-comparison.md)・[通知・履歴の記録](performance/2026-11-06-runtime-cost.md)。
- 確認: 全テスト 4,098件成功、実機で Apple 接続の復元・歌詞・分割・HOME 復帰([Task 201](../tasks/201-v2.3.1-release.md))。

## 2.3.0(2026-11-04)版47

- Apple Music で再生中の曲は、Apple の単語同期歌詞を優先して表示する(取れなければ AMLL → LRCLIB)。ホームと分割パネルの両方。
- 設定 →「音楽」→「Apple Music の歌詞」から、YLuncher 内で Apple にログインして接続できる。接続情報は端末内に暗号化して保存し、再起動・更新の後も復元する。手動のトークン入力もある。
- 接続を解除するとき、YLuncher 内の Web ログイン情報も消すかを選べる。
- Apple 歌詞の通信で IPv6 の接続待ちが続くとき、IPv4 も素早く試す。
- ジャケット背景を最大3色にした(文字のコントラスト 4.5:1 以上を保つ)。
- 既知: 起動直後に設定画面が一時的に黒くなることがある(原因未特定)。確認の範囲は [Task 190](../tasks/190-v2.3.0-release.md)。

## 2.2.0(2026-11-04)版39

負荷を減らした(見た目・動きは変えていない)。

- 歌詞は、見えている行と出入りする行だけを組み立てる。
- ホーム・パネルのアプリ情報(一覧・名前・アイコン)を裏で取って共有する。
- 本体のリリース版に R8 をかけた(APK 約 42MB → 約 2.6MB)。
- ベースラインプロファイルを入れた(端末の待機中の最適化の後に効く。すぐ効かせるなら `adb shell cmd package compile -r bg-dexopt com.gt8d.launcher`)。
- 実機の計測(2.1.0 比): ホームに戻るまで 120ms → 83ms、1フレームの処理の 90% 値 14.2ms → 11.3ms。

## 2.1.0(2026-11-04)版37

- 歌詞の取得元に [AMLL TTML DB](https://github.com/amll-dev/amll-ttml-db) を足した(単語ごとの時刻つき)。Apple Music の曲はカタログの曲 ID で直接、他のアプリは1日1回取る索引から曲名・アーティストで決まるときだけ取る。
- 優先順位は AMLL → LRCLIB の同期歌詞 → LRCLIB の平文。AMLL に無い曲は、再生のたびに AMLL だけを確かめ直す。

## 2.0.0(2026-11-04)版33

- ミニプレイヤーとパネルのメディアカードの地を、ジャケットから取った暗い色のグラデーションにした。
- 歌詞の見た目: 次の行を少し明るく、行ごとに少しずつ遅れて動く送り、今の行以外をわずかに縮める。

## 1.7.1(2026-11-03)版30

- 歌詞の行送りとフェードを滑らかにした。歌詞の文字を 22sp に。
- ホームの描画を軽くした。リリース版ではホーム・パネル・幕をユーザー補助に「パネル」1つとして見せる(読み上げで中の部品は読めない)。
- 歌詞のキャッシュに単語の時刻も保存する。

## 1.7.0(2026-11-03)版25

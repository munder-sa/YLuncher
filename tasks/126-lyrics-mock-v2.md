## 決まったこと(ユーザーの確認済み)
1. **案A(ジャケットと歌詞の切り替え)だけ**を残す。寸法・色・余白・文字の大きさは Task 124 の案Aのまま(1 CSS px = 1dp、外寸 409dp 幅、角丸 24dp、余白 上・左右 40/下 32dp)。
2. **切り替えボタン**: 「歌詞」の文字のチップをやめ、案1のアイコンボタンにする。72dp の円、図柄は**見た目で 40dp**(SVG の viewBox の余白で小さくならないように、図柄の外形が約 40dp になるよう大きさを合わせる)。オフ=#454550 の地+白い図柄、オン=白い地+#0B0B0F の図柄。aria-label「歌詞を表示」/「ジャケットを表示」、aria-pressed。
3. **はみ出さない配置**:
   - 高さに余裕があるとき(アプリ名の行を出すとき): アプリ名の行の右端に置く。行の高さは 44dp のまま、ボタン(72dp)は行の縦中央に合わせ、**カードの内側の余白(上 40dp・右 40dp)の内に収める**。行の上下に 14dp ずつはみ出す分は、行の前後の余白として確保する(上の余白 40dp の中に食い込ませない。必要ならアプリ名の行の下の余白を増やす)。
   - 高さが足りずアプリ名の行を出さないとき: ボタンを**曲名・アーティストの行の右端**に移す(既存の☆と同じ置き方。8dp 空けて縦中央)。☆もあるときは「曲名の列 → 8dp → 歌詞ボタン → 8dp → ☆」の順。
   - ページ上部の操作に「☆あり/なし」を追加し、両方の場合を確認できるようにする。
4. **上下の端を薄くぼかす**: 歌詞の表示領域の上端・下端それぞれ 32dp を、mask-image の線形グラデーションで透明→不透明にぼかす。行が途中で切れても、くっきりした切れ目が見えないこと。
5. **前へ/次へは曲送り**: 歌詞の行の移動に使わない。モックでは押すと曲を変えたことにする(位置 0:00 に戻り、曲名を「ダミーソング」⇔「ダミーソング2」で入れ替え、歌詞の状態も「同期歌詞あり」⇔「歌詞なし」で入れ替えて、自動でジャケットに戻る様子を見せる)。
6. **歌詞が無いときは自動でジャケットに戻す**:
   - 歌詞の状態が「歌詞なし」「オフライン」のときは、ボタンがオンでもジャケットを表示する。ボタンは無効の見た目(不透明度 0.38、押せない)にし、ボタンのすぐ下に小さく(16sp、#B0B0BB)「歌詞なし」/「オフライン」と出す(アプリ名の行の右端のときは行の外に出さず、ボタンの左に出す)。
   - ユーザーのオン/オフの選択は覚えておき、歌詞が取れる状態に戻ったら(状態の切り替え、または曲送り)オンなら歌詞に戻る。
   - 「取得中」は、オンなら歌詞の場所に弱い色で「歌詞を探しています…」。オフならジャケットのまま。
   - 「同期なし」は全文を静止表示し、手で縦スクロールできる(端のぼかしは同じ)。
7. 高さの切り替え(694dp/500dp)と再生・シーク・状態の切り替えは Task 124 と同じく残す。694dp と 500dp で、上記3の2つの置き方が見られること。

- 歌詞は Task 124 の架空のダミー文を使い回す(実在の曲の歌詞を使わない)。
- 外部の CDN・フォント・画像を使わない1ファイル。

# 指示書の共通ルール(すべての tasks/NNN-xxx.md に適用)

指示書を読む前に、このファイルを読み、従うこと。

1. **決めたことを全部並べる**: 指示書に書いていないことを自分で決めたら(名前、値、アルゴリズム、ライブラリの使い方、テストの書き方、エラー時の扱いなど)、最後の報告に「**決めたこと**」という見出しを作り、1行ずつすべて並べる。何も決めていなければ「決めたこと: なし」と書く。
2. **推測で進めない**: 「〜のはず」「〜と思われる」で進めない。動作を確かめられないこと(Android の API の挙動、端末の仕様、指示書の解釈が2通り以上ありうることなど)に当たったら、そこで作業を止め、何が分からないかと、考えられる選択肢を報告して終わる。
3. **調べ物で許可外のコマンドを使わない**: SDK やライブラリの中身を調べるためのコマンド(`javap`、`find`、`grep` など)は、指示書の許可に無ければ実行しない。必要なら止めて質問する。ファイルを読むことは許可なしでできる。
4. **テストを弱めない**: テストの期待値を、実装に合わせて変えない。仕様と食い違うと思ったら、直さずに報告して止まる。
5. **確認していないことを「確認した」と書かない**: 報告には、実際に実行したコマンドと、その結果(テストの実行件数・失敗件数)を書く。

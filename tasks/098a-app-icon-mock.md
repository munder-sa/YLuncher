# Task 098a: YLuncher のアプリのアイコンの案を4つ作る(モック)

最初に `tasks/RULES.md` を読み、従うこと。

## 背景
YLuncher(GT8D の車載ランチャー。画面を「左のアプリ | 右のパネル」などの画面セットで分割して使う。パネルは時計・ミニプレイヤー・アプリのアイコン・ドックを持つ)のアプリのアイコンを作り直す。今のアイコン(`app/src/main/res/drawable/ic_launcher_foreground.xml`・`ic_launcher_background.xml`)は暗い地に2つの枠と緑の ▶・音符。強調色は**白**に統一した(緑はやめる)。地は暗い色(`#0B0B0F`〜`#2E2E38` の系統)。中継アプリ `com.gt8d.launcher.panel`(パネルを分割の片側に出すための小さなアプリ)にもアイコンが要る(今は指定なし)。本体と中継は**同じ系統で見分けがつく**こと。

## 作るファイル(これで全部)

## 仕様
1. 案を4つ。各案は Android のアダプティブアイコン(108x108 の viewport、中央 66x66 が安全な範囲)として、**前景と背景**をインラインの SVG で描く(後で vector drawable に移せる、path・rect・circle だけ。グラデーションは背景だけ可)。
   - 案A: 「Y」の字形を、左右の分割の枠で表す(Y の縦線が仕切り)。
   - 案B: 左右 6:4 の2つの角丸の枠(画面セット)+ 右の枠の中に小さなドックの縦線。
   - 案C: 運転席から見た画面のイメージ(横長の角丸の画面の中に仕切りの線と、片側に時計の「12:00」を思わせる2本の短い線)。
   - 案D: codex が考える最良の案(理由を1行)。
2. 各案ごとに: 本体のアイコンと、中継アプリのアイコン(同じ系統で、例えば本体を反転・小さな印を付けるなど)。
3. 表示: 1行に1案。各案で、本体と中継のそれぞれを (a) 円のマスク 192px、(b) 角丸の正方形のマスク 192px、(c) 48px(小さい表示)、(d) 黒い背景のアプリ一覧に他のアプリのアイコン(YouTube 風の赤・Chrome 風の円など、ダミーの単純な図形)と並べた見え方、で並べる。案の名前と1行の説明。全体の幅は 1200px 以内、背景は暗い色。
4. 強調は白。暗い地の上で 48px でも形が分かること。

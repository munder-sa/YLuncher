# Task 128: 歌詞モックの切り替えボタンの右端をそろえる(使い捨ての検討用)

`design/mocks/lyrics-miniplayer.html`(Task 127 の版)だけを直す。ほかは変えない。

## 直すこと
- 今は、48dp の見える囲みが 72dp の押せる範囲の中央にあるため、囲みの右端が内容の右端(シークバー・残り時間の右端=カードの右の内側余白 40dp の線)より 12dp 内側に入っている。
- **見える囲みの右端を、内容の右端(シークバーの右端)にそろえる**。アプリ名の行の右端に置くときも、曲名の行の右端に置くときも同じ(☆があるときは☆が右端なので、歌詞ボタンは「曲名の列 → 8dp → 歌詞ボタンの囲み → 8dp → ☆」の見た目の間隔にする)。
- 押せる範囲は 72dp 四方を保つ。はみ出す分は囲みの外側(右・上下)へ広げてよい(カードの余白に重なってよい。ほかの押せる要素とは重ならないこと)。
- 縦の位置は今のまま(行の縦中央)。

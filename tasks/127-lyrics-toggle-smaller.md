# Task 127: 歌詞モックの切り替えボタンを小さく、角丸の四角にする(使い捨ての検討用)

`design/mocks/lyrics-miniplayer.html`(Task 126 の版)の、歌詞↔ジャケットの切り替えボタンの見た目だけを変える。ほかの動き・配置の決まり(高さに余裕があればアプリ名の行の右端、無ければ曲名の行の右端、☆との並び、歌詞なし時の無効表示と「歌詞なし」の文字)は変えない。

## 変更するファイル(これ以外は変えない)
- `design/mocks/lyrics-miniplayer.html`

## 変更(ユーザーの指示: 「アイコンはもっと小さくてよい」「囲みは角を取った四角。丸だと悪目立ちする」)
- 見える囲み: **48dp の正方形、角丸 12dp**(仕様の「内側の部品 12dp」に合わせる)。円はやめる。
- 図柄: 案1「吹き出し+行」の SVG のまま、**見た目で 28dp**(線幅は 2.5dp 程度。小さくしても線が細くなりすぎないように調整)。
- 押せる範囲は **72dp 四方のまま**(見えない余白で確保。見た目の囲みはその中央)。押せる範囲が他の要素と重ならないこと(重なるなら、見た目の囲みの位置はそのままで押せる範囲だけ調整し、決めたことに書く)。
- 色: オフ = #454550 の地+白い図柄、オン = 白い地+#0B0B0F の図柄、無効 = 不透明度 0.38(今と同じ)。
- アプリ名の行(44dp)の右端に置くとき、48dp の囲みは行の縦中央に合わせ、カードの内側の余白(上・右 40dp)からはみ出さないこと。
- ☆(72dp の丸)は既存の仕様のものなので変えない。

- 読み取りのみ(cat, sed -n, rg, ls)。ビルドやテストは不要。

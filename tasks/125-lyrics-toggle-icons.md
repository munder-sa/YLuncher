# Task 125: 歌詞↔ジャケットの切り替えボタンのアイコン案(HTML の一覧、使い捨ての検討用)

アプリのコードは変えない。Task 124 のモック(`design/mocks/lyrics-miniplayer.html`)も変えない。

## 作るファイル(これ以外は作らない・変えない)
- `design/mocks/lyrics-toggle-icons.html`(新規。外部の CDN・フォント・画像を使わない1ファイル。アイコンはすべてインライン SVG で自分で描く。既存アプリのロゴや商標の図柄をそのまま写さない)

## 前提
- ミニプレイヤーの地の色 #2E2E38、文字 白、弱い色 #B0B0BB、操作の地 #454550。1 CSS px = 1dp。
- ボタンは 72dp の円(押せる大きさ 72dp)、図柄は 36〜40dp。Material の icon toggle button に寄せる。
- 2つの状態を必ず並べる:
  - **オフ(ジャケット表示中)**: 地なし、または #454550 の地+白い線の図柄
  - **オン(歌詞表示中)**: 白い円の地+暗い(#0B0B0F)図柄(既存の再生ボタンと同じ強調)。線の図柄なら塗りの版にしてもよい

## アイコン案(各案に番号・名前・一言の説明。6案)
1. **吹き出し+行**: 角丸の吹き出しの中に横線2〜3本(歌詞=言葉)
2. **行の強調**: 横線3本で、真ん中の1本だけ太く長い(同期歌詞の「今の行」)
3. **音符+行**: 左に音符、右に横線2〜3本
4. **マイク**: シンプルなマイク(カラオケ)
5. **引用符の吹き出し**: 吹き出しの中に「“」(歌詞の引用)
6. **行き先を示す切り替え**: 押すと移る先を図柄にする。ジャケット表示中は「行」の図柄、歌詞表示中は「正方形の画像(山と丸)」の図柄。この案だけ、オン時に図柄が変わることを示す

## 並べ方
- 1案ごとに1枚のカード(地 #2E2E38、角丸 24dp)。カードに「オフ」「オン」のボタンを実寸で横に並べ、その下に小さいサイズ(48dp)の版も並べる。
- ページの下に、Task 124 の案Aの上部(アプリ名の行 44dp と右端のボタン)を実寸で再現した帯を1本置き、上の操作でアイコン案を選ぶとその帯のボタンが切り替わるようにする(ボタンを押すとオン/オフが入れ替わる)。
- 白黒どちらの状態でも図柄の太さ(線幅 2.5〜3dp 程度)をそろえる。

## 使ってよいコマンド
- 読み取りのみ(cat, sed -n, rg, ls)。ビルドやテストは不要。

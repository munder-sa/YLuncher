## 内容(上から順。見出しと文はこのとおり、言い回しは整えてよい)
0. 上部のナビ: 「YLuncher」+ ページ内リンク(特徴 / 画面 / 使い方 / 導入 / FAQ)。スクロールしても上に固定。
1. ヒーロー: 見出し「2つの画面を、ひと押しで。」、小見出し「GT8D のためのランチャー。左右の分割を『画面セット』として保存し、すぐに呼び出す。」。home.png を大きく。ボタン「特徴を見る」「導入方法」(ページ内リンク)。版の表示「v1.6.1」。
2. 特徴(カード 6 枚、2〜3 列のグリッド。各カードに短い見出し+2行程度の説明。アイコンは絵文字を使わず、CSS の図形か頭文字の丸で):
   - 画面セット: 左右のアプリ・比率・パネルの位置をまとめて保存し、ひと押しで再現。仕切りのダブルタップで入れ替えた左右も保存。
   - リンクは隣に開く: 今のアプリを残したまま、外部ブラウザを分割の反対側に開く。開くブラウザは設定で選べる。
   - パネル: 時計・ミニプレイヤー・アイコン・ドックを狭い幅に。左右どちらにも置ける。アプリとセットの表示を切り替え。
   - 端のジェスチャ: ほかのアプリを使っていても、画面の端から次・前のセットやホームへ。
   - 止まらない切り替え: 切り替え中は幕で覆い、時間がかかれば知らせ、失敗しても安全にホームへ戻る。
   - よく使うアプリが自動でドックに: 直近 7 日間の使い方から並べる。
3. 画面: 5 枚のスクリーンショットと1行の説明。home と set-panel は大きく、残り3枚は3列。画像は角丸・影。クリックで原寸を新しいタブで開く(<a href> で)。
4. 使い方(3 ステップ、番号つき横並び): ① 設定でセットを作る(左右のアプリと比率を選ぶ) ② ホームのカードを押すか、端のジェスチャで呼び出す ③ リンクやアプリは隣に開く。
5. 導入: 動作環境(GT8D・Android 15)。APK は2つ(本体 com.gt8d.launcher → 中継 com.gt8d.launcher.panel の順に install -r、同じ署名鍵)。最初に要る許可(使用状況へのアクセス、通知へのアクセス、ほかのアプリの上に表示、通知)。再インストール後は通知へのアクセスを許可し直す。詳細は ../install-v1.6.md へのリンク。コマンドは <pre><code> で: `adb install -r app-release.apk` → `adb install -r panelhost-release.apk` → `adb shell cmd notification allow_listener com.gt8d.launcher/com.gt8d.launcher.media.MediaListenerService`。
6. FAQ(<details><summary> で開閉、5 問):
   - なぜアプリが2つあるの? → 純正の分割は右側のアプリを「既存のタスク」から選ぶ。パネルを独立したアプリ(中継)にして、その中にパネルを開くことで、分割の右側に安定して置ける。
   - 再起動の後にセットが開かない → 既定のホームが YLuncher だと、再起動後に純正ランチャーが一度も開かれず、純正の分割が反応しない。v1.6.2 から、必要なときだけ純正ランチャーを一瞬開いて準備する。
   - 音楽が表示されない → 再インストールで通知へのアクセスが外れる。許可し直す。
   - 分割が失敗したら? → 幕が閉じて知らせが出る。もう一度押すか、設定の「許可のチェック」を確認。
   - 純正のホームに戻したい → 設定の「純正ランチャーに戻す」。
7. 設計の考え方: 運転中に迷わない(大きな押す場所、最小 72dp)、シンプル(案内の文字を置かない)、Material 3 に沿った崩れない見た目。
8. フッター: 「YLuncher v1.6.1 — 自分用のメモ」と作成日 2026-11-01。

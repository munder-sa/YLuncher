# Task 124: パネル(ホーム)のミニプレイヤーに歌詞を出す案の HTML モック(使い捨ての検討用)

アプリのコードは変えない。ブラウザで開いて見比べるための HTML を1枚作る。

## 作るファイル(これ以外は作らない・変えない)
- `design/mocks/lyrics-miniplayer.html`(新規。外部の CDN・フォント・画像を使わない、1ファイルで完結。CSS と JS は中に書く)

## 寸法と見た目の前提(既存の実装に合わせる)
- 参考: `app/src/main/java/com/gt8d/launcher/ui/home/HomeMiniPlayer.kt`、`docs/superpowers/specs/2026-10-28-gt8d-launcher-design.md` の §4.4(ミニプレイヤー)と寸法表。
- 1 CSS px = 1dp として描く。ミニプレイヤーの外寸は 409×694dp(画面 726dp から上下 16dp を引いた高さ)、角丸 24dp、地の色 #2E2E38。外側の余白は上・左右 40dp、下 32dp(内幅 約 329dp)。
- 色: 背景 #0B0B0F、文字 白、弱い文字 #B0B0BB、操作の地 #454550。再生/一時停止は 96dp の白い丸に暗い図柄、前へ/次へは 72dp。
- 既存の並び: アプリ名の行(36dp アイコン+名前、高さ 44dp)→ ジャケット(正方形、角丸 8dp)→ 曲名(28sp 太め、1行)+アーティスト(20sp、弱い色)→ シークバーと経過/残り時間 → 下端に操作ボタン。
- ジャケットは画像を使わず、グラデーションの四角で代用する。

## 並べる3案(横に並べ、各案に見出しと一言の説明を付ける)
- **案A: ジャケットと歌詞の切り替え** — アプリ名の行の右端に「歌詞」の切り替えボタン(押せる大きさ 72dp 以上。見た目は丸い輪郭のチップ)。オンでジャケットの場所が歌詞になる。今の行を白・26sp・太めで中央付近に、前後の行を #B0B0BB・20sp で上下に1〜2行ずつ。行が変わるときは 300ms ほどで上へ滑らかに送る。
- **案B: 小さいジャケット+歌詞** — ジャケットを 96dp に縮め、曲名・アーティストの左に置く(横並び)。空いた高さに歌詞を3〜5行(今の行を強調)。
- **案C: 歌詞を1行だけ** — 既存の並びはそのままに、アーティストの下(シークバーの上)に今の行を1行だけ出す(22sp、白、長い行は省略記号)。ジャケットは高さが足りない分だけ縮む。

## 動き(ページ上部の操作パネルで切り替え、3案に同時に効く)
- 再生/一時停止(各案の再生ボタンでも同じ)。再生中は時間が進み、同期歌詞の今の行が変わる。シークバーをクリックするとその位置へ移る。
- 状態の切り替え: 「同期歌詞あり」「同期なし(行の時刻なし。全文をゆっくり読めるよう静止表示、案Cは1行目のみ)」「取得中(弱い色で「歌詞を探しています…」)」「歌詞なし(弱い色で「歌詞が見つかりません」。案Aはジャケットに戻せる案内、案Cは行ごと消す)」「オフライン(「オフラインのため歌詞を表示できません」)」。
- 高さの切り替え: 694dp(ホーム)と 500dp(狭い場面を想定)。高さが減ったとき各案がどう縮むか(既存同様、アプリ名の行→ジャケットの順で縮む/消える)を再現する。
- 歌詞の文面は**架空のダミー文**を自分で書く(実在の曲の歌詞を使わない)。日本語の短い行を 12〜16 行、各行に時刻(0:00〜3:30 の範囲、曲の長さ 3:30)を付ける。曲名「ダミーソング」、アーティスト「サンプルアーティスト」、アプリ名「Apple Music」。1行だけ長い行(省略・折り返しの確認用)を入れる。

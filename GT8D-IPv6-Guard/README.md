# GT8D IPv6補助

GT8DのWi-Fi用IPv6通信が、SIM側のIPv6経路へ流れ込む現象を回避するための専用アプリです。

パッケージ名: `local.gt8d.ipv6guard` / バージョン: 1.1

## 背景と実機確認（2026年11月18日）

- GT8D 5GではSIMがONなら、モバイルデータがOFFでも `rmnet_data2` が `proto ra` のIPv6デフォルトルートを `main` テーブル（32766）に追加します。このためAOSP標準の `32000: from all unreachable` が必要です。
- 旧版の `/data/local/gt8d-ipv6-guard/guard.log` にある15回分の起動履歴で、ルール32000は起動ごとに1回追加すれば再起動まで消えないことを確認しました。
- `adbd` の起動残留（`service.adb.listen_addrs` の未クリアを含む）と10秒周期の監視ループがAndroid Auto / DHUのレイテンシーを悪化させていたため、v1.1ではワンショット適用に変更します。

## v1.1の動作

- 起動完了時に `/system/bin/ip -6 rule show` でルールを非root確認します。設定済みなら最終確認時刻を更新するだけで、ADBには触れません。
- 未設定の場合だけ端末内のUnixソケット `localabstract:gt8d-ipv6-guard` を準備し、rootで `ip -6 rule add priority 32000 unreachable` を一度だけ実行します。このアプリ用のTCP待受は公開しません。
- ワンショット処理の直後に `service.adb.listen_addrs` を空にし、`ctl.stop adbd` でADBサービスを完全停止します。途中で失敗した場合も後片付けを実行します。
- 起動前にワイヤレスデバッグが有効だった場合は、停止の代わりにADBサービスを再起動して通常の待受へ戻します。端末内ソケットが最初から待受中だった場合（carprobe使用中など）は、プロパティ変更やADBサービスの停止・再起動を行いません。
- 後片付け後にルールを再度非root確認し、未設定なら再試行の対象にします。`guard.sh` の生成や常駐監視は行いません。
- 失敗時の再試行と15分間隔のAndroidジョブは維持し、ルールの有無を確認します。ジョブの実行時刻はAndroidの制御を受けます。ルール設定済みならジョブもADBを起動しません。
- IPv6全体を無効化する処理ではありません。通常のネットワーク選択でSIMを使う際のIPv6は残します。

## 旧版からの更新

自動適用が有効なら、適用処理の先頭で旧版の `enabled` フラグファイルを削除します。削除に成功すると旧 `guard.sh` は10秒以内に終了します。ルール設定済みの場合もこの処理を行いますが、ADBは起動しません。

`/data/local/gt8d-ipv6-guard` が削除されるのは、ルール未設定時にワンショットを投入するとき、または再起動後の初回適用時です。旧PIDファイルの値が数字で、対象プロセスのコマンドラインに旧 `guard.sh` のパスがある場合だけ停止してから、ディレクトリを削除します。更新直後にルールが設定済みなら、このディレクトリは次のワンショット投入まで残ります。

## このGT8Dでの動作条件

Android 15（SDK 35）、ADBシェルがroot、ADB認証が無効、SELinuxがPermissiveの実機向けに作成しました。これらは作業前からの状態です。アプリはSELinux設定を変更しません。

このファームウェアでは通常のアプリから必要な起動用プロパティを設定できることを確認しました。v1.1では必要な場合だけ `service.adb.listen_addrs` を端末内ソケットに設定し、適用後すぐにクリアします。設定変更はアプリから `/system/bin/setprop` を直接実行して行います。

Magiskの導入、system/vendorの書き換え、ブートイメージの変更、ADBのTCP待受の永続化は行っていません。ファームウェア更新などで権限やADBの仕様が変わると、この方法が動かなくなる可能性があります。

起動から適用まで、および消失から再適用までには時間差があります。起動直後から一切の経路漏れを許さない方式ではありません。

## 操作

初回起動で自動適用を有効にします。通常はその後、アプリを開く必要はありません。

- 「状態を更新」: 自動適用の有効・停止、現在のルール、ワンショット方式、最終確認時刻を表示します。ADBは使用しません。
- 「今すぐ適用」: ルールを確認し、未設定の場合だけワンショット適用します。
- 「自動適用を停止」: 次回起動時の適用と再試行・定期ジョブを停止します。ADBは使用せず、現在のIPv6ルールは再起動まで残します。

アプリを強制停止すると、Androidの仕様上、手動で再度開くまで起動通知やジョブが止まる場合があります。

## 解除

アプリで「自動適用を停止」してからアンインストールします。v1.1は常駐プロセスを作りません。旧版の監視が残っている場合は、停止操作による旧フラグの削除で10秒以内に終了します。

現在のIPv6ルールもすぐに解除したい場合は、自動適用を停止し、旧版の監視が終了してからroot ADBで以下を実行します。

```sh
ip -6 rule del priority 32000 unreachable
```

## 診断用の場所

- アプリのログ: `/data/user_de/0/local.gt8d.ipv6guard/files/events.log`
- アプリ設定: `/data/user_de/0/local.gt8d.ipv6guard/`（有効状態と最終確認時刻はSharedPreferencesに保存）
- 旧版の残骸: `/data/local/gt8d-ipv6-guard/`（v1.1では作成せず、上記のワンショット投入時に削除）

## ソースとビルド

ソースZIPにはJavaソース、マニフェスト、ローカル用ビルドスクリプトを含めています。外部ライブラリは使いません。

ビルドにはJDK、Android SDK Platform 35、Build Tools 36.0.0が必要です。`build.ps1` 内のSDK・JDK・出力先のパスを使用環境に合わせて変更してください。署名鍵 `guard-signing.p12` のパスワードは環境変数 `GT8D_GUARD_KS_PASS` で渡します(未設定ならビルドは止まります)。端末に入っている版へ上書きインストールするには、既存の鍵を作ったときのパスワードを設定してください。

配布するソースZIPに署名用秘密鍵は含めません。新しい鍵でビルドしたAPKは、インストール済みのものへ上書きできません。今回の作業環境には、更新用の元の署名鍵を保管しています。
